# 论文精读：A Mechanistic Account of Attention Sinks in GPT-2

Yuval Ran-Milo, Hila Ofek, Shahar Mendel · Tel Aviv University · ACL 2026 Short Papers · pp. 90–98

[论文 PDF](https://aclanthology.org/2026.acl-short.9.pdf) · [官方代码与数据](https://github.com/YuvMilo/MechanisticAccountofSinks) · [arXiv 版本](https://arxiv.org/abs/2604.14722)

这篇论文研究的是 Transformer 机制可解释性（Mechanistic Interpretability）中一个非常具体、但具有普遍意义的问题：

**为什么 GPT-2 的许多 Attention Heads 会持续把大量注意力分配给第一个 Token，即使它并没有重要的语义信息？**

作者没有满足于观察 Attention Map，而是进一步追踪这种行为如何从模型参数和中间表征中产生，并通过因果干预（Causal Intervention）验证自己的解释。

## 一、先建立对整篇论文的理解

我建议先抓住它最重要的三个结论。

**第一，作者在 GPT-2 中发现了一条能够产生 Attention Sink 的具体计算通路。**

<!-- visualization: circuit -->

三个要素分别是：

- **Query Bias**：学习得到的 Query 偏置项，对所有 Query 位置都起作用。
- **Effective Positional Encoding（EPE）**：第一个位置的原始位置编码经过首层 MLP 变换后，形成特殊的表征。
- **Key Projection \(W_K\)**：将这种特殊表征投影到与 Query Bias 高度对齐的方向。

它们共同提高了第一个位置的 Attention Logit，使大量 Query 将注意力分配给该位置。

**第二，论文提供了强于普通相关性分析的因果证据。**

在原始 GPT-2 中，作者测得的平均 BOS Attention 为 0.563。清除 Query Bias 后下降到 0.251；将第一个位置的位置编码替换为第二个位置的位置编码后，更降至 0.017。

这说明作者识别的计算路径确实参与了产生 Attention Sink，而不仅仅与它同时出现。

**第三，也是整篇论文最值得注意的结论：这条通路并不是 Attention Sink 的普遍形成机制。**

作者指出，其他没有这些特定组件的模型架构仍然会产生 Attention Sink。

因此，这篇论文回答了一个局部问题：

> 在 GPT-2 中，哪些参数和中间表征共同实现了 Attention Sink？

但没有彻底回答更深的问题：

> 为什么不同架构、不同训练条件下的 Transformer 都倾向于学习出 Attention Sink 这种行为？

我认为这是理解全文贡献边界的关键：**作者识别了一条具体的 Mechanistic Circuit，但尚未建立 Attention Sink 的普遍形成理论。**

## 二、Research Problem：Attention Sink 究竟是什么，为什么需要研究？

### 2.1 从 Attention 的计算重新理解这个现象

对于 Decoder-only Transformer，某个 Attention Head 中，第 \(i\) 个 Token 对第 \(j\) 个 Token 的注意力为：

\[
\alpha_{ij}=
\frac{\exp(q_i k_j^\top/\sqrt{d_h})}
{\sum_{t\le i}\exp(q_i k_t^\top/\sqrt{d_h})}
\]

这里：

- \(q_i\)：当前位置产生的 Query，代表它要寻找什么信息。
- \(k_j\)：历史位置产生的 Key，参与 Query–Key 匹配。
- \(\alpha_{ij}\)：位置 \(i\) 分配给位置 \(j\) 的注意力权重。
- \(d_h\)：单个 Attention Head 中 Query 和 Key 的维度。

通常，我们希望模型依据上下文内容，动态决定关注哪些 Token。

但实际的 GPT-2 可能呈现如下模式。

<!-- visualization: heatmap -->

在正常的内容匹配模式下，不同 Query 可以关注不同历史位置。

在 Attention Sink 模式下，许多不同 Query 都将较大的权重分配给第一个位置。这会在 Attention Map 上形成明显的高亮竖列。

值得强调：**Attention Sink 是对注意力权重分布的描述，不等于第一个 Token 对最终预测有很大贡献。**

因为 Attention Output 实际上是：

\[
o_i=\sum_{j\le i}\alpha_{ij}v_j
\]

即使 \(\alpha_{i1}\) 很大，如果对应的 Value 向量在输出投影后贡献很小，那么模型也可能几乎没有从第一个 Token 读取有用的语义信息。

这就产生了一个研究问题：模型为什么要把有限的注意力概率分配给一个未必有用的位置？

### 2.2 这个问题为什么重要？

至少有三个层面的价值。

首先是 **机制可解释性**。如果 Attention Sink 主要来自固定的参数偏置和位置表征，那么将某个 Head 的注意力集中解释为它在读取 BOS Token 的语义，就可能产生误判。

其次是 **推理系统优化**。StreamingLLM 等工作发现，即使较早 Token 的语义价值很低，直接丢弃它们的 KV Cache 也可能破坏后续推理；保留少量初始 Token 的 KV 能够显著改善流式生成的稳定性。

最后是 **架构与训练机制设计**。如果理解了 Attention Sink 如何产生，就可能设计新的注意力计算方式或训练策略，减少不必要的注意力集中，同时保持模型能力。

不过，这里必须区分两个目标：

- 解释 Attention Sink 的形成机制；
- 证明消除 Attention Sink 可以改善模型性能。

**本论文直接研究的是第一个目标，并没有完成第二个目标的系统验证。**

## 三、Prior Work：此前的研究已经解释到了什么程度？

这篇论文并不是首次发现 Attention Sink，也不是首次把它与 Massive Activations 联系起来。

要正确评价创新性，需要区分三条研究路线。

### 3.1 从现象发现到工程应用：StreamingLLM

Xiao et al., ICLR 2024

*Efficient Streaming Language Models with Attention Sinks* 首先展示了一个重要的工程问题：

采用 Sliding Window Attention 进行长文本推理时，如果仅保留最近的 KV Cache，语言模型的表现可能明显恶化。

但若在窗口之外额外保留最初少量 Token 的 KV Cache，模型就能保持更稳定的生成质量。

这说明最初的 Token 在注意力计算中具有某种特殊作用，哪怕其文本内容并不重要。

StreamingLLM 利用了这个现象，却没有在 GPT-2 的具体参数层面解释为什么会出现这种特殊注意力模式。

### 3.2 从经验规律到形成条件：When Attention Sink Emerges

Gu et al., 2025 · arXiv:2410.10781

这篇工作更接近 Attention Sink 的形成理论。

作者研究了 Attention Sink 在训练过程中的出现时间，以及训练数据、Loss Function、模型结构等因素的影响。

其中一个重要解释是：

**Attention Sink 可以表现为一种隐式 Key Bias，用于吸收 Softmax Attention 中未必需要分配给有用内容的概率质量。**

考虑 Softmax 的约束：

\[
\sum_{j\le i}\alpha_{ij}=1
\]

无论当前 Query 是否真的需要历史信息，Softmax 都必须将总量为 1 的概率分配出去。

因此，一个合理的功能假说是：模型可能需要一个可以稳定承接注意力概率、但不会引入太多无用信息的位置。

该研究还发现，在其测试的模型和训练设置中，将归一化 Softmax Attention 替换成无需归一化的 Sigmoid Attention，可以避免 Attention Sink 的出现。

但需要注意：这提供的是关于形成条件和可能功能的证据，并没有说明 GPT-2 究竟通过哪些参数实现这种行为。

### 3.3 从中间表征到具体计算通路：Massive Activations

2024 年的 *Massive Activations in Large Language Models* 发现，大模型中少量隐藏维度的激活值可能远大于其他维度。这些异常值往往与 Attention Sink 相关，可以充当隐式偏置。

之后，Jack Dial 在 *The Curious Case of the BOS Token* 中进一步追踪了 GPT-2 中与 Sink 相关的特征，发现早期 MLP 会增强这种特征，而下游 Query 会与相应的 Key 方向对齐。

本论文与这些工作的联系最直接。

它在 Appendix B 中明确指出，自己的增量主要是把已有观察组织成可以验证的参数级因果机制：

1. 将早期 MLP 产生的特殊位置表征形式化为 EPE。
2. 验证 EPE 与真实位置贡献之间的关系。
3. 找到 EPE、Query Bias 和 Key Projection 之间的数学联系。
4. 通过干预区分位置编码、Token Embedding 和 MLP 变换各自的作用。

### 3.4 如何评价作者的研究动机？

可以将相关研究的进展概括如下：

| 研究 | 主要解决的问题 | 仍然留下的问题 |
|---|---|---|
| StreamingLLM | Sink 有什么工程作用？ | 参数层面如何产生？ |
| When Attention Sink Emerges | 什么时候形成？受什么影响？ | GPT-2 的具体实现是什么？ |
| Massive Activations / Dial | 哪些隐藏特征与 Sink 有关？ | 完整计算通路与因果作用是什么？ |
| **本文** | GPT-2 如何实现 Sink？ | 为什么训练会选择它？其他架构如何实现？ |

研究动机是充分的，因为此前的工作没有完整解释从位置编码到 Attention Logit 的因果路径。

但创新性应被准确定位为：**在既有 Attention Sink 与 Massive Activation 研究基础上的机制细化和因果验证**，而不是提出了一个全新的 Attention Sink 理论。

## 四、Core Intuition：为什么 Query Bias、EPE 和 Key Projection 能共同制造 Sink？

这是整篇论文最关键的部分，也是值得深入推导的数学。

### 4.1 第一步：展开 Attention Logit

为了避免符号过多，先固定一个 Transformer Layer 和一个 Attention Head，省略层、头下标。

GPT-2 的 Query、Key 采用线性映射与可学习偏置：

\[
q_i=x_iW_Q+b_Q,\qquad k_j=x_jW_K+b_K
\]

其中 \(x_i,x_j\in\mathbb R^D\)，而 \(q_i,k_j,b_Q,b_K\in\mathbb R^{d_h}\)。

Attention Logit 在除以 \(\sqrt{d_h}\) 之前是：

\[
s_{ij}=q_ik_j^\top
\]

代入并展开：

\[
\begin{aligned}
s_{ij}={}&
\underbrace{(x_iW_Q)(x_jW_K)^\top}_{A}\\
&+\underbrace{(x_iW_Q)b_K^\top}_{B}\\
&+\underbrace{b_Q(x_jW_K)^\top}_{C}\\
&+\underbrace{b_Qb_K^\top}_{D}
\end{aligned}
\]

观察这四项与位置 \(i,j\) 的关系：

| 项 | 依赖 Query 位置 \(i\)？ | 依赖 Key 位置 \(j\)？ |
|---|---|---|
| A：内容相关匹配 | 是 | 是 |
| B：Key Bias 交互 | 是 | 否 |
| C：Query Bias 交互 | 否 | 是 |
| D：两个 Bias 的内积 | 否 | 否 |

这里可以发现一个重要的数学事实。

对固定的 Query \(i\)，B、D 两项对于所有可见 Key 位置 \(j\) 都是常数。

而 Softmax 具有平移不变性：

\[
\operatorname{softmax}(z+c\mathbf 1)
=\operatorname{softmax}(z)
\]

所以 B、D 虽然出现在 Logit 里，却不会影响当前 Query 在各 Key 之间的相对注意力分布。

于是对 Softmax 真正有效的部分可以写成：

\[
\boxed{
s_{ij}\equiv
(x_iW_Q)(x_jW_K)^\top+\Delta_j
}
\]

其中 \(\equiv\) 表示两侧产生相同的 Softmax 分布，并定义

\[
\boxed{
\Delta_j=b_Q(x_jW_K)^\top
}
\]

这就是论文 Section 3.1 的核心：**Source-Agnostic Shift**。

### 4.2 为什么 Source-Agnostic 如此重要？

注意：

\[
\Delta_j
\]

只取决于目标位置 \(j\)，不取决于当前发起查询的位置 \(i\)。

如果某个目标位置 \(j=1\) 对应的 \(\Delta_1\) 远大于其他位置，那么所有 Query 的 Attention Logit 都会获得同一种偏置：

\[
s_{i1}\longleftarrow s_{i1}+\Delta_1
\]

换句话说，模型不必让每个 Query 都主动学习去寻找第一个 Token。

它只需要让第一个 Token 的 Key 表征与一项所有 Query 共享的偏置对齐，就能在许多不同 Query 中提高它的分数。

<!-- visualization: softmax-slider -->

这里的关键不是“第一个 Token 本身携带了更多信息”，而是它获得了一个对许多 Query 通用的分数优势。

进一步看，如果其他 Logit 保持不变：

\[
\alpha_{i1}
=
\frac{e^{(a_{i1}+\Delta_1)/\sqrt{d_h}}}
{e^{(a_{i1}+\Delta_1)/\sqrt{d_h}}+\sum_{j=2}^{i}e^{(a_{ij}+\Delta_j)/\sqrt{d_h}}}
\]

其中 \(a_{ij}\) 表示内容相关的匹配分数。

对 \(\Delta_1\) 求导：

\[
\frac{\partial\alpha_{i1}}{\partial\Delta_1}
=
\frac{\alpha_{i1}(1-\alpha_{i1})}{\sqrt{d_h}}>0
\]

因此，在其他分数固定时，提高 \(\Delta_1\) 必然提高第一个 Token 的 Attention Weight。

这是一个严格的数学结论。

但它只证明了这种机制**能够**产生 Sink。至于训练好的 GPT-2 是否真的采用它，还需要分析实际参数和实验干预。

### 4.3 第二步：为什么 \(\Delta_1\) 特别大？

将公式换一种等价形式：

\[
\Delta_j=b_QW_K^\top x_j^\top
\]

定义

\[
\gamma=b_QW_K^\top\in\mathbb R^D
\]

便有：

\[
\boxed{\Delta_j=\gamma x_j^\top}
\]

这相当于一个内积：

- \(\gamma\) 是由 Query Bias 和 Key Projection 共同确定的方向。
- \(x_j\) 是第 \(j\) 个位置的隐藏表征。

如果 \(x_1\) 在某些维度上有极大的值，而且 \(\gamma\) 恰好在这些维度上具有较大且同向的分量，那么 \(\Delta_1\) 就会很大。

用坐标形式展开：

\[
\Delta_1=\sum_{d=1}^{D}\gamma[d]x_1[d]
\]

这揭示了两种可能性：

一种是许多维度共同贡献一个较大的内积。

另一种是极少量维度产生特别大的乘积，主导整个结果。

论文发现，GPT-2 中出现的是第二种情况——少数异常大的激活坐标发挥了关键作用。

### 4.4 第三步：EPE 从哪里来？

GPT-2 使用 Learned Absolute Positional Embedding。

进入 Transformer 时：

\[
x_i^{(0)}=e_i+p_i
\]

其中 \(e_i\) 是 Token Embedding，\(p_i\) 是 Position Embedding。

但经过第一层 Transformer 后，传递到下游的已经不是简单的 \(e_i+p_i\)。

MLP 会对输入进行非线性变换，经过残差连接后，位置信息也随之改变。

作者定义：

\[
\boxed{\mathrm{EPE}_i=p_i+\mathrm{MLP}^{(1)}(p_i)}
\]

将其称为 Effective Positional Encoding。

这里有一个必须澄清的细节：**EPE 并不是实际 Transformer 中严格分离出来的全部位置贡献。**

因为：

\[
\mathrm{MLP}(e_i+p_i)
\ne \mathrm{MLP}(e_i)+\mathrm{MLP}(p_i)
\]

对于非线性 MLP，该等式一般不成立。

此外，真实的 Transformer Block 还包含 Attention、LayerNorm 和残差计算。

因此，EPE 是一个有明确物理意义、但需要经验验证的近似量，而不是从网络结构直接推出的严格等式。

论文随后会专门验证这个近似是否可靠。

### 4.5 将三者组合起来

作者的机制解释可近似表示为：

\[
\begin{aligned}
\Delta_1
&=b_QW_K^\top x_1^\top\\
&\approx b_QW_K^\top\mathrm{EPE}_1^\top
+\text{其他表征贡献}
\end{aligned}
\]

这里将 EPE 视为位置 1 中与 Sink 有关的一部分表征，并非宣称它完全等于 \(x_1\)。

如果：

\[
b_QW_K^\top\mathrm{EPE}_1^\top
\]

非常大，那么第一个位置就会获得显著的 Source-Agnostic Shift。

这就是全文的 Core Intuition：

> 第一层 MLP 把第一个位置编码转换成特殊的高幅值表征；下游 Key Projection 与 Query Bias 又恰好在这些维度上对齐，于是这个位置被赋予对大量 Query 普遍有效的注意力分数优势。

这个机制同时解释了三个观察：

1. 为什么 Sink 对第一个 Token 的具体语义内容不敏感；
2. 为什么许多不同 Attention Heads 会出现相似的首位置偏好；
3. 为什么早期 MLP、位置编码和后续 Attention 参数会共同参与这个现象。

不过，原论文并未证明训练期间这三个部分是如何逐步形成这种协同关系的。

## 五、Method：从真实输入到 Attention Sink 的完整过程

我们沿用论文中的 GPT-2 研究对象，并用一个简化示例说明。

假设模型输入为：

\`The cat sat on the mat.\`

这里没有必要假设模型一定添加特定的 BOS Token。我们只需关注序列中的第一个位置，即 Position 1。

### Step 1：输入 Token 和位置信息

假设第一个位置是 \`The\`，其初始隐藏表征是：

\[
x_1^{(0)}=e_{\mathrm{The}}+p_1
\]

其余位置则是：

\[
x_j^{(0)}=e_j+p_j
\]

模型既知道 Token 是什么，也能通过位置编码区分不同位置。

### Step 2：第一层 MLP 形成特殊位置特征

经过第一层 Attention、MLP 和残差等操作，隐藏表征发生变化。

作者观察到，与第一个位置有关的 EPE 含有少数极端大的坐标值。

在 GPT-2-small 中，Appendix A.2 识别出了三个坐标：**138、378、447**。

这是论文实测的坐标索引，而不是示意数字。

这三个坐标上的 \(\lvert\mathrm{EPE}_1[d]\rvert\) 超过平均绝对值三个标准差以上，且各自距均值超过 15 个标准差。

也就是说，在 768 维的 GPT-2 Hidden State 中，只有很少几个维度表现出极端特殊性。

但这里不能直接说这些维度“存储了 BOS 的语义”。

作者的分析恰恰表明，它们与第一个**位置**的表征有关。

### Step 3：后续 Transformer Layers 读取这个特征

当隐藏表征进入后续层时，不同 Attention Heads 具有自己的 \(W_K\) 和 \(b_Q\)。

如果某个 Head 的参数满足：

\[
\gamma[d]=(b_QW_K^\top)[d]
\]

在这些异常激活维度上也很大，且乘积方向匹配，就会有：

\[
\Delta_1
=
\sum_d\gamma[d]x_1[d]
\gg \Delta_j
\]

这一步是整个机制的核心：**原本属于 Residual Stream 的特殊表征，经过 Key Projection 与 Query Bias 的交互，被转换成一种注意力分数偏置。**

### Step 4：Softmax 将分数优势转化为注意力集中

如果第一个位置的 Logit 显著高于其他位置，那么 Softmax 会将较大概率分给 Position 1。

对于不同的 Query，这种现象会重复出现。

最终输出的 Attention Map 就表现为第一列明显偏亮。

需要注意，论文关注的是这种 Attention Pattern 的来源。后续 Value Aggregation、Output Projection 和最终的 Token Prediction 并不是作者因果分析的主要终点。

**这也是为什么不能从本文直接推导出“删除 Sink 可以改善最终预测”。**

## 六、Experimental Design：作者如何证明这条 Circuit 真的存在？

这篇论文的实验设计有一个清楚的逻辑：

先找到与 Sink 相关的异常信号，再解释异常信号从哪里来，最后直接干预相关组件。

其证据链可以分成四个层次。

### 6.1 实验对象与评价指标

论文 Section 3.2.1 的实验设置如下。

| 项目 | 设置 |
|---|---|
| 模型 | GPT-2 Small，124M 参数 |
| 预训练权重 | \`openai-community/gpt2\` |
| 数据集 | SST-2、GSM8K、HumanEval |
| 样本数量 | 每个数据集 100 条，共 300 条 |
| 输入长度 | 保留至少 40 Tokens 的样本，并截断为 40 Tokens |
| Attention Heads | 分析全部 Heads |
| 主要层范围 | Layers 4–11，全文采用 0-based 之外的论文层编号表达 |
| 主要指标 | BOS Attention |

这里还存在一个重要的实验设计选择：作者不分析所有层，而是集中研究 Attention Sink 相对明显的中后层。

这有利于研究机制，但不能用所得结论直接代表整个模型的所有层。

另外，SST-2、GSM8K 和 HumanEval 涵盖了自然语言、数学和代码三类不同内容，但作者并没有在这些数据集上进行情感分类、数学推理或代码生成性能评测。

**这些数据集在本文中提供的是不同输入分布，不是三个独立的下游任务性能实验。**

#### BOS Attention 如何定义？

作者将它定义为序列后半部分 Query 对第一个位置分配的平均注意力权重，再对指定层和所有 Heads 聚合。

可以表示为：

\[
B=
\frac{1}{|\mathcal L|H|\mathcal I|}
\sum_{l\in\mathcal L}
\sum_{h=1}^{H}
\sum_{i\in\mathcal I}
\alpha^{(l,h)}_{i1}
\]

其中：

- \(\mathcal L\)：分析的 Layer 集合；
- \(H\)：每层 Head 数量；
- \(\mathcal I\)：输入后半段的 Query 位置；
- \(\alpha^{(l,h)}_{i1}\)：第 \(l\) 层第 \(h\) 个 Head 中，位置 \(i\) 对位置 1 的 Attention Weight。

为什么只看后半段 Query？

因为 Causal Mask 会让最早的 Query 几乎没有其他可以关注的位置。

例如，第一个 Query 只能关注自己，其 Attention Weight 必然等于 1。

如果将它也纳入指标，就会高估真正由模型参数产生的 Sink 强度。

作者选择后半段位置，是为了减小这种由 Causal Mask 导致的结构性偏差。

但这种指标仍然受到序列长度影响。因此，作者将所有输入统一为 40 Tokens，以提高不同样本之间的可比性。

### 6.2 Figure 1：证明存在异常大的 Source-Agnostic Shift

作者计算每个 Head 中：

\[
\Delta_j=b_QW_K^\top x_j^\top
\]

由于 Softmax 对所有目标位置统一加常数不敏感，因此作者对每组数据减去最小的 \(\Delta_j\)，使其最小值为零。

这样可以在不改变注意力分布的情况下比较不同 Head 的结果。

**原论文 Figure 1：Source-Agnostic Shift 的分布**

[查看原论文 Figure 1（PDF）](https://aclanthology.org/2026.acl-short.9.pdf)

Figure 1 中：

- 红色表示 Position 1 的 \(\Delta_1\)。
- 蓝色表示其他位置的 \(\Delta_j\)。

红色分布整体显著右移。

也就是说，Position 1 具有特殊的、跨 Query 生效的分数优势。

这支持作者提出的第一步解释：GPT-2 中的 Sink 不完全来自内容相关的 Query–Key 匹配，还涉及独立于 Query 位置的偏置项。

但 Figure 1 本身仍是相关性证据。它不能排除这个项只是与 Sink 同时出现、而非真正驱动 Sink。

### 6.3 Figure 3：EPE 是否真能代表实际位置贡献？

这是方法中一个容易忽略但很关键的验证。

作者将实际增加位置编码前后的 MLP 输出进行比较，定义：

\[
N_i=
\left(e_i+p_i+\mathrm{MLP}(e_i+p_i)\right)
-
\left(e_i+\mathrm{MLP}(e_i)\right)
\]

这是在简化的首层 MLP 路径中，由引入位置编码带来的净变化。

然后比较：

\[
\cos(\mathrm{EPE}_i,N_i)
=
\frac{\mathrm{EPE}_i^\top N_i}
{\|\mathrm{EPE}_i\|\|N_i\|}
\]

如果这个值接近 1，说明 EPE 与实际位置贡献的方向非常接近。

| 指标 | 相似度 |
|---|---|
| 所有位置的中位余弦相似度 | ≥ 0.82 |
| Position 1 的相似度 | ＞ 0.99 |

这说明 EPE 对第一个位置尤其准确。

不过，如果把第一层中的 Attention、Normalization 等实际运算也纳入比较，论文报告 Position 1 的中位余弦相似度下降到 **0.76**，第 10 和第 90 百分位数分别为 0.67 和 0.80。

这是一个很有价值的细节。

它表明 EPE 是对 MLP 位置贡献的高质量代理，但对完整 Transformer Block 的真实位置贡献只能做到中等偏高的近似。

所以不能简单地将 EPE 当作真实模型中完全独立、精确可加的位置特征。

### 6.4 Figure 2 与 Figure 4：解释异常 Shift 从哪里来

接下来作者验证两个互补的假设。

**假设 A：第一个位置的 EPE 经 \(W_K\) 投影后，与 Query Bias 特别对齐。**

作者计算：

\[
\cos\left(b_Q,\mathrm{EPE}_jW_K\right)
\]

Figure 2 显示，Position 1 的余弦相似度大多位于较高的正值区域，而其他位置主要表现为负向对齐。

这个结果支持一种解释：由于第一个位置的 EPE 与 Query Bias 对齐，它会系统性提高 \(\Delta_1\)。

**假设 B：这种对齐主要来自少数 Massive Activation Coordinates。**

作者分析：

\[
\gamma[d]=(b_QW_K^\top)[d]
\]

特别比较 \(\lvert\gamma[d]\rvert\) 在前述三个异常维度与其他维度上的分布。

Figure 4 显示，Massive Activation 所在维度的投影系数幅值明显更大。

这将原本宏观的几何现象进一步落实到了少数隐藏维度。

但从审稿人的角度，这两幅图仍主要证明方向对齐和幅值关联，而不直接证明它们造成了 Attention Sink。要完成因果推断，必须改变这些变量并观察实际注意力的变化。

### 6.5 Table 1：最重要的因果干预实验

我认为 Table 1 是全文最有说服力的证据。

作者在已经训练完成的 GPT-2 上进行前向干预，而不重新训练模型。

每一项干预都对应一个机制假设，并与原始模型及相关控制组比较。

**论文 Table 1，BOS Attention：均值 ± 2 SE**

| 干预 | BOS Attention | 保留比例 |
|---|---:|---:|
| Baseline | 0.563 ± 0.004 | 100.0% |
| Nullify Query Bias | 0.251 ± 0.003 | 44.7% |
| Remove First PE | 0.017 ± 0.001 | 3.0% |
| Swap EPE | 0.035 ± 0.002 | 6.2% |
| Swap Raw PE | 0.557 ± 0.006 | 99.0% |
| Nullify BOS Token | 0.561 ± 0.004 | 99.7% |
| Disable All MLPs | 0.283 ± 0.009 | 50.3% |
| Remove All PE | 0.099 ± 0.015 | 17.5% |
| Zero Top-3 \(W_K\) Coordinates | 0.367 ± 0.004 | 65.2% |
| Zero Random \(W_K\) Coordinates | 0.563 ± 0.004 | 100.0% |

<!-- visualization: intervention-bars -->

观察这些实验，关键不只是每一项干预能降低多少注意力，而是不同干预之间的对照关系。

#### 对照一：Token Identity vs Positional Information

清除 BOS Token Embedding：

\[
B:0.563\rightarrow 0.561
\]

几乎没有变化。

但将第一个位置的 PE 替换为第二个位置的 PE：

\[
B:0.563\rightarrow 0.017
\]

注意力集中几乎消失。

由此可见，在这份 GPT-2 权重和这些输入上，造成 Sink 的主要因素不是第一个 Token 的具体 Embedding，而是与第一个位置有关的特殊信息。

这比“换一个 BOS Token 后 Sink 还在”的观察更有力，因为它直接干预了输入表征的不同组成部分。

不过，Remove First PE 也会影响位置 1 的其他下游计算，并不能孤立证明 EPE 是唯一中介。

#### 对照二：Raw PE vs EPE

这是我认为设计最巧妙的一组实验。

干预 Raw PE 的方向，BOS Attention 仍为 0.557，接近 Baseline 的 0.563。

但干预 EPE 方向后，BOS Attention 降至 0.035。

这说明模型下游注意力依赖的，不仅仅是原始 Position Embedding，而更接近首层 MLP 已经处理过的特殊方向。

要准确理解这里的 Swap，需要读 Appendix B.1。

作者并没有简单交换两个完整向量，而是在首层 MLP 输出中，沿特定位置方向移除一个投影分量，再在另一位置注入相同系数的方向分量。

设首层 MLP 输出为 \(m_1,m_2\)，并定义两个单位方向：

\[
\hat u_j=\frac{u_j}{\|u_j\|}
\]

其中 \(u_j\) 可以是 \(\mathrm{EPE}_j\) 或 \(p_j\)。

令：

\[
a=m_1^\top\hat u_1
\]

作者进行：

\[
\begin{aligned}
m_1'&=m_1-a\hat u_1+a\hat u_2\\
m_2'&=m_2+a\hat u_1-a\hat u_2
\end{aligned}
\]

这样移除和注入的投影分量具有相同的系数幅值。

严格来说，这个操作保持的是被替换分量的幅值，而不保证整个 \(m_1'\) 或 \(m_2'\) 的范数不变。

这一点很重要，因为作者希望测试**位置相关的方向信息**，而不是仅仅测试将激活整体放大或缩小的效果。

也需要明确：论文 Table 1 测量的是原始位置 1 的注意力下降，并没有在表中定量展示被替换到位置 2 的注意力增加多少。因此，“Sink 被移动到了新位置”这一更强说法需要与 Figure 5 及补充分析结合解读，不能只凭表格证实。

#### 对照三：Top-3 Key Projection Coordinates vs Random Coordinates

作者清除 \(W_K\) 中与三个 Massive Activation 维度对应的投影参数。

结果：

\[
B:0.563\rightarrow0.367
\]

但如果清除随机选择的三个对应维度，BOS Attention 仍为 0.563。

这支持一种具有局部化特征的机制解释：不是随便修改三个 Key Projection 维度都能减少 Sink，而是与 Massive Activation 对齐的特定维度发挥了作用。

这里还有一个限制：只清除三个维度后，仍然存在约 65% 的基线 BOS Attention。

因此，这三个维度有实质性的因果作用，但并不能解释全部 Sink。

#### 对照四：去掉 Query Bias 后仍然保留了多少 Sink？

将全部层的 Query Bias 置零后，BOS Attention 从 0.563 降至 0.251。

这意味着：

\[
1-\frac{0.251}{0.563}\approx55.4\%
\]

大约 55% 的基线 BOS Attention 指标被削减，但还有约 45% 保留。

所以这里的严谨结论是：

**Query Bias 对 GPT-2 中强烈的 Attention Sink 具有重要因果作用，而不是 Sink 在数学意义上必须依赖 Query Bias。**

这也与论文最后提出的“不同架构存在不同实现路径”保持一致。

## 七、Results & Analysis：这些实验结果究竟证明了什么？

我们现在把 Figure 1–5 与 Table 1 组合起来，而不是将每个实验孤立看待。

### 7.1 证据链：从异常表征到因果机制

1. **观察 Attention Sink**：模型对 Position 1 分配异常高的注意力，构成需要解释的现象。
2. **分解 Logit，找到异常偏置项**：Figure 1 表明，第一个位置具有异常大的 Source-Agnostic Shift。
3. **定位异常偏置的来源**：Figure 2、3 表明，第一个位置的 EPE 能很好地近似相关位置贡献，并与 Query Bias 的 Key 空间方向高度对齐。
4. **追踪到少数隐藏维度**：Figure 4、7 表明，少数 Massive Activation Coordinates 与 Key Projection 的相应方向存在显著对应关系。
5. **进行因果验证**：Table 1 和 Figure 5 表明，移除或干预这条通路中的关键组件，可以大幅降低 Attention Sink，而部分控制干预不会产生相同效果。

其中前四步主要属于结构分析与相关性证据，第五步才提供较直接的因果证据。

因此，本文最强的结论是：在所研究的 GPT-2 权重中，作者提出的 \(b_Q\)–EPE–\(W_K\) 路径，是形成大量首位置注意力的重要因果通路。

这个结论有较强支持。

### 7.2 一个反直觉结果：删除第一个位置的 PE，比删除全部 PE 更有效

观察 Table 1：

- Remove First PE：0.017
- Remove All PE：0.099

直觉上，删除全部位置编码似乎应该比只删除一个位置编码造成更大的 Sink 下降。

但实验结果相反。

这说明两项干预并不具有简单的包含关系。

模型中存在非线性运算、归一化、多层信息交互。如果清除全部位置编码，整个隐藏状态分布和注意力计算都会改变，可能产生其他分数偏置。

所以不能认为：

\[
\text{删除更多组件}\Rightarrow\text{Sink 必然更弱}
\]

这个反直觉结果支持模型机制具有非线性耦合的可能性。

但论文没有对这种差异给出完整的中介分析，因此以上解释属于**合理推断，而不是作者通过实验确定的机制**。

更严格的后续研究应当检查 Remove All PE 后剩余的 Attention Sink 来自哪些 Logit 项。

### 7.3 另一个重要结果：EPE 是良好的代理，却不是完整的真实表征

Figure 3 给出了 Position 1 超过 0.99 的余弦相似度，这看起来接近完美。

但是把完整第一层的运算纳入计算后，相似度中位数降至 0.76。

这揭示出两个不同层次的结论：

- EPE 很好地描述了作者所研究的简化 MLP 路径中的位置信号。
- EPE 并不能精确覆盖真实 Transformer Block 中的全部位置相关变化。

第二点不直接推翻论文的结论，因为一个近似代理也可以准确刻画最重要的因果方向。

但如果将来希望构建更加精确的 Mechanistic Circuit，便需要把 Attention、LayerNorm、残差传播与后续 MLP 的影响进一步纳入分析。

### 7.4 最深刻的结论：同一种行为可以由不同的 Circuit 实现

作者在 Conclusion 中指出：

- 一些没有 Query Bias 的模型仍具有 Attention Sink。
- 一些没有 MLP 的 Transformer 仍具有 Attention Sink。
- 一些没有显式位置编码的 Transformer 仍具有 Attention Sink。

这与本文在 GPT-2 中识别的三组件机制并不矛盾。

原因是：

**某个组件对一个模型中的某条计算通路具有因果作用，不代表所有架构实现同一种行为都必须使用这个组件。**

可以把 Attention Sink 看作某种计算行为，而 GPT-2 中的 \(b_Q\)–EPE–\(W_K\) 只是实现该行为的一种方式。

作者进一步推测，训练优化可能会根据模型结构，在可用组件之间寻找实现相同计算行为的替代路径。

这是很有启发性的猜想，但本文尚未通过跨架构的机制追踪或从头训练实验验证这一点。

## 八、Critical Evaluation：作为审稿人，我如何评价这篇论文？

### 8.1 论文的主要贡献与证据强度

| 研究主张 | 我的评价 | 证据情况 |
|---|---|---|
| GPT-2 存在由 Query Bias 引起的首位置分数偏置 | 强 | 数学分解、Figure 1、Query Bias 消融 |
| 首层 MLP 处理过的位置信息参与形成 Sink | 强 | EPE 近似验证、EPE/PE 对照干预 |
| 少数 Massive Coordinates 参与放大偏置 | 较强 | Figure 4、7、定向与随机 \(W_K\) 消融 |
| 所识别路径完整解释 GPT-2 的 Sink | 不充分 | 消融后仍存在残余 Sink |
| 不同架构的 Sink 存在不同参数级实现 | 合理但尚未充分机制验证 | 主要结合其他研究的跨架构观察 |
| Attention Sink 是优化过程中必然形成的功能性结构 | 尚未证明 | 缺少训练动态和功能性实验 |

综合来看，论文最有价值的科学贡献不是发现 EPE、Query Bias 或 Massive Activation 中的任意单个因素，而是建立了这些因素之间的数学联系，并用有针对性的干预验证了它们的因果作用。

### 8.2 我认为最需要关注的四个问题

**问题一：单个 GPT-2 Checkpoint 的泛化性有限。**

作者采用一个 124M 参数的预训练 GPT-2，虽然分析了 300 个不同领域的输入，但并没有系统研究不同模型规模、不同随机种子、不同训练配置。

多个输入样本可以支持对当前模型行为的统计稳定性判断，却不能自动证明该 Circuit 对不同训练得到的 GPT-2 都成立。

如果同样的架构在另一个训练随机种子下形成了不同的 Circuit，那么论文的发现就更接近对某个具体 Checkpoint 的解释，而不是整个 GPT-2 架构的普遍规律。

**问题二：部分干预同时影响其他计算路径。**

例如，No MLP 实验禁用了全部 MLP，而不仅是第一层。

这会大范围改变 Residual Stream，使后续 Attention Heads 接收到与原训练分布不同的输入。

因此，观察到 Sink 下降，只能说明被移除的 MLP 计算整体对现象具有重要作用，不能单凭这一项实验证明首层 MLP 是唯一关键环节。

作者使用 EPE Swap 缩小了这个问题，但仍值得进行更细粒度的 Path-Specific Intervention。

**问题三：机制解释与模型功能之间缺乏直接联系。**

论文测量的主要终点是 Attention Weight。

但对于 Language Modeling，更进一步的问题是：

\[
\text{Attention Sink}
\longrightarrow
\text{Attention Output}
\longrightarrow
\text{Residual Stream}
\longrightarrow
\text{Final Logits}
\]

这条影响路径究竟如何？

如果清除 Sink 后，Perplexity 基本不变，说明该现象可能具有较强的可替代性，或者其主要作用是调节注意力分配。

如果清除 Sink 后，Perplexity 明显恶化，那么至少说明这些干预对语言建模能力有破坏性影响，但仍需排除干预对其他有用计算路径的直接破坏。

由于作者没有提供对应的下游性能结果，无法仅凭本文判断消除 Sink 究竟是否有益。

**问题四：没有解释 Circuit 的学习过程。**

本文对训练完成的网络进行了静态分析。

但真正的形成机制，还包括训练期间不同参数如何共同演化。

例如：

- 是第一个位置的 Massive Activation 先出现，然后 \(W_K\) 和 \(b_Q\) 逐步与之对齐？
- 还是 Query Bias 先形成，促使 MLP 学习出能够与之配合的位置特征？
- 这些特征的形成是否依赖 Softmax 归一化？
- 训练数据中的首位置统计规律是否参与了这一过程？

本文无法回答这些问题。

这也是为什么静态的 Mechanistic Interpretability 研究与 Training Dynamics 研究具有互补性。

## 九、如果继续推进研究，最值得做哪些实验？

结合目前关于 Attention Sink、Gated Attention 和 Attention Head 消融的研究方向，我认为下面三个实验最有价值。

### 9.1 实验一：从 Attention Weight 追踪到最终预测

优先级：高 · 可直接利用原作者公开的 GPT-2 代码扩展

问题是：

**破坏本文识别的 Sink Circuit，会改变多少最终预测能力？**

可以在现有干预基础上，对每一种实验配置额外记录：

- BOS Attention；
- 各层 Attention Output 的变化；
- 各层 Residual Stream 的变化；
- Language Modeling Cross-Entropy / Perplexity。

特别是，不仅测量：

\[
\Delta \alpha_{i1}
\]

还可以比较最终输出分布：

\[
D_{\mathrm{KL}}
\left(
P_{\mathrm{baseline}}(\cdot\mid x)
\parallel
P_{\mathrm{intervention}}(\cdot\mid x)
\right)
\]

这样可以检验：Attention Sink 明显减弱时，模型最终输出是否也发生相应变化。

需要使用相同输入和预测目标，确保比较的是同一位置上的概率分布。

如果出现 Attention Weight 大幅变化，而 Logit 分布变化较小的现象，就能进一步研究注意力分配与最终功能贡献之间的脱钩程度。

这个实验与你此前关注的 Attention Head Ablation 十分相关，但这里的消融对象从整个 Head 变成了 Head 内部的特定计算通路。

### 9.2 实验二：跨模型比较实现同一 Sink 的不同 Circuit

优先级：高 · 机制研究价值最大

可以选取三类模型：

| 架构 | 重点研究的问题 |
|---|---|
| GPT-2 | 有 Query Bias、Learned Absolute PE，能否复现本文 Circuit？ |
| 无 Query Bias 的 Transformer | 是否存在其他源无关或近似源无关的偏置机制？ |
| 使用 RoPE 的现代 Decoder | 是否通过不同的隐藏特征或参数结构形成 Sink？ |

对于缺少显式 \(b_Q\) 的模型，可以从更一般的 Query 表征分解出发，寻找输入变化较小时相对稳定的方向，而不预先假定存在与 GPT-2 完全相同的参数。

但必须注意：这种稳定方向是否等价于显式 Query Bias，需要独立验证。

该研究能够检验本文提出的一个重要推断：

> 同一种 Attention Sink 行为，是否真的能够通过参数不同、但计算功能类似的 Circuit 实现？

如果能够发现两种不同架构中的不同计算路径分别承担类似功能，就会比简单观察“两个模型都有 Sink”更有解释力。

## 十、综合评价：这篇论文的真正位置

我会把这篇论文定位为一项**具有较强局部因果证据的 Mechanistic Interpretability 工作**。

它最值得学习的不是某一张 Attention Heatmap，也不只是找到了三个异常维度，而是它采用了一条比较规范的机制研究路径：

\[
\boxed{
\text{现象}
\rightarrow
\text{数学分解}
\rightarrow
\text{候选计算通路}
\rightarrow
\text{结构证据}
\rightarrow
\text{因果干预}
}
\]

在这一框架下，作者成功解释了 GPT-2 中一种重要的 Attention Sink 实现机制。

但是，这并不是一种通用的 Attention Sink 形成理论，也不能证明 Attention Sink 对所有任务都有害，更不能据此认为只要删除 Query Bias 或相关 EPE，就能普遍提升大模型性能。

相反，论文最具启发性的开放问题恰好是：

**为什么在缺少 GPT-2 这条特定 Circuit 的模型中，训练优化仍然可能产生相似的 Attention Sink 行为？**

这个问题可以将本文与两类研究联系起来：

一类是 [When Attention Sink Emerges in Language Models](https://arxiv.org/abs/2410.10781)，侧重训练过程与 Softmax 机制。

另一类是 [Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free](https://arxiv.org/abs/2505.06708)，侧重修改 Attention 的计算结构，以改变模型的注意力行为。

前者问的是现象为什么形成，后者探索如何改变它，而本文提供的是一个具体模型中这种现象如何被参数实现的精细解释。

对后续科研而言，我建议优先吸收本文的两种方法：**把 Attention Score 分解为具有明确数学意义的贡献项，以及利用成对的 Causal Interventions 排除替代解释**。

这比仅通过 Attention Matrix 聚类或比较注意力分布来解释 Head 的语义角色，能够提供更直接的机制证据。

**进一步阅读**

- [When Attention Sink Emerges in Language Models](https://arxiv.org/abs/2410.10781)：研究训练条件、Softmax 和 Sink 形成的关系。
- [Massive Activations in Large Language Models](https://arxiv.org/abs/2402.17762)：理解少数异常隐藏维度如何发挥隐式偏置作用。
- [Gated Attention for Large Language Models](https://arxiv.org/abs/2505.06708)：研究架构设计如何改变 Attention Sink 行为。
- [Attention Sinks Are Provably Necessary in Softmax Transformers](https://arxiv.org/abs/2603.11487)：从特定理论任务出发，研究 Softmax Transformer 中 Sink 的必要性；其适用范围不能直接推广为所有模型或任务的普遍定理。

最终，这篇论文提供的科学结论可以浓缩为一句话：

**GPT-2 的 Attention Sink 不只是注意力图上的统计异常，而是可以追踪到具体参数、隐藏维度和计算路径，并通过因果干预验证的模型内部行为；但这一局部机制的发现，仍与 Attention Sink 的普遍形成原因和功能解释相距一步。**
