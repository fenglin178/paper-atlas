Gated Attention for Large Language Models: Non-linearity, Sparsity, and Attention-Sink-Free

Softmax 决定从哪里读取信息；输出门控让当前 token 决定，这次读取的结果应该写入多少。一个很小的架构变化，连接起表达能力、训练稳定性与 Attention Sink。

阅读结论与证据边界

最值得保留的发现

在每个头的 SDPA 输出之后、输出投影之前加入由当前输入生成的 sigmoid 乘法门控，能以较低开销改善模型表现。位置、头间独立性和允许门控接近零，都影响收益。

本文是大规模架构消融与机制分析研究。较充分的证据支持性能提升、训练更稳定及首 token 注意力显著下降；“减少 Sink 导致外推改善”仍是机制假说。以下“论文实测”“作者解释”“审稿推断”“待验证”分别标明证据性质。数值沿用 v1 的表号，不混入后续实现结果；示意图不代表真实模型激活。

01 / Research Problem：Attention 还缺什么控制？

对第 i 个 token、第 h 个头，因果注意力计算为：

aᵢⱼʰ = softmaxⱼ(qᵢʰ·kⱼʰ / √dₖ),　zᵢʰ = Σⱼ≤ᵢ aᵢⱼʰvⱼʰ

其中 q、k、v 分别是 Query、Key、Value，dₖ 是头维度；a 非负且每行和为 1。注意力解决了信息来源的相对分配，但没有独立的“本次少写入或不写入”变量。模型仍可通过 Value 抵消或输出投影间接完成抑制，因此不能说普通 Attention 绝对无法执行 no-op。

例如处理 “The capital of France is Paris” 时，某个头可以把读取集中于 France；但当前计算是否需要这个头提供的特征，是另一个自由度。门控把“从哪里读”与“读完后传递多少”分开。这是教学例子，并非论文中的语言学实验。

研究的价值还在于理解 Attention Sink：即使初始 token 没有明显语义作用，部分头仍持续给它高权重。已有研究提出，Softmax 必须分配完概率质量，模型可能借助一个相对无害的位置承接冗余权重。输出门控为抑制信息提供另一条路径，但这不是所有 Sink 的统一已证实成因。

02 / Prior Work：贡献来自系统拆解

LSTM、GRU 与 Highway Networks 已用门控管理信息流；SwiGLU 将其用于 Transformer FFN；状态空间模型和线性注意力也常使用门控。因此“把 Gate 加入神经网络”并非创新点。

前人工作与本文关系本文进一步追问
Quantizable Transformers让头能够近似不做事，缓解异常值；已经研究门控注意力。不同门控位置和形式，何者在大规模训练中更好？
StreamingLLM保留初始 KV，利用已有模型的 Sink 实现稳定流式推理。从训练架构上改变信息控制，是否还会形成同样的 Sink？
When Attention Sink Emerges通过预训练干预研究归一化、Key Bias 与 Sink 形成。标准 Softmax 保留时，输出门控如何改变 Sink？
Forgetting Transformer把遗忘门引入 Softmax 注意力。聚合后的当前 Query 条件门控，与历史信息衰减有何不同？

审稿判断：本文的增量是将门控位置、粒度、头共享、加法/乘法和激活函数拆开对照，并连接到优化与可解释性。研究动机充分，但不能把所有门控收益归为首次发现。

03 / Method：输入、聚合、门控与输出

输入 X∈ℝⁿˣᵈ 是 pre-norm 后的隐藏状态，n 为序列长度、d 为模型宽度。每个头分别形成 Q=XWQ、K=XWK、V=XWV，执行含因果遮蔽的 SDPA。最佳配置对应原文 §2.2、式 (5) 的 G₁：

gᵢʰ = σ(xᵢWGʰ),　ẑᵢʰ = zᵢʰ ⊙ gᵢʰ
oᵢ = Concat(ẑᵢ¹,…,ẑᵢᴴ)WO,　σ(t)=1/(1+e⁻ᵗ)

H 为 Query 头数；⊙ 为逐元素乘法。Elementwise 版本的 gᵢʰ∈(0,1)ᵈₖ，每头每维独立控制；Headwise 每头仅产生一个标量并广播到各维。Head-specific 表示不同头有各自门控，并不要求每个头拥有一个独立运行的网络。门控来自当前 xᵢ，不是直接把 Q 投影向量当成门控。

G₁ 在聚合完成后由当前需求决定输出；G₂ 则给各历史位置的 Value 先加门控：

G₁: [Σⱼ aᵢⱼvⱼ] ⊙ σ(xᵢWG)
G₂: Σⱼ aᵢⱼ[vⱼ ⊙ σ(xⱼWG)]

G₂ 的选择随来源位置 j 变化，同一来源会被所有能看到它的 Query 复用；G₁ 随当前 i 变化。一般不能把两者交换。其余位置为 G₃：Key 投影后，G₄：Query 投影后，G₅：WO 后。对 Q/K 的门控改变匹配几何；G₅ 在多个头混合后才抑制输出。

为什么作者强调两次线性映射之间的非线性？

oᵢʰ = [Σⱼ aᵢⱼʰxⱼWVʰ]WOʰ = Σⱼ aᵢⱼʰxⱼ(WVʰWOʰ)
rank(WVʰWOʰ) ≤ dₖ

WVʰ∈ℝᵈˣᵈₖ，WOʰ∈ℝᵈₖˣᵈ 是输出矩阵中对应头的块。多个头经各自 WOʰ 后应求和，与先拼接后乘 WO 等价。固定注意力权重时，这条 Value 路径可以合并为固定的低秩映射；整个 Attention 仍因 Q/K 与 Softmax 而是输入依赖的非线性函数。

Dᵢʰ = diag(gᵢʰ),　oᵢʰ = Σⱼ aᵢⱼʰxⱼ WVʰDᵢʰWOʰ

门控引入随 xᵢ 变化的映射族；它没有突破每次条件化矩阵的 dₖ 秩上界。准确的解释是增加输入条件化的乘法交互，而不是“门控使低秩矩阵变成满秩”。GQA 中 Value 投影由一组 Query 头共享，头独立的输出门控仍可提供不同的控制。

04 / Experimental Design：每组对照检验什么？

论文设置（§3.1）：15B 总参数、约 2.54B 激活参数的 MoE（128 experts、top-8、GQA）和 1.7B Dense；预训练上下文 4096，数据含多语言、数学与通识，总数据池 3.5T tokens。不是所有 30 余个变体都训练了 3.5T tokens：主要 MoE 架构消融用 400B，Dense 有 400B、1T 与 3.5T 等设置。

  1. 位置与预算：Table 1 同训练配置比较 G₁–G₅；增加 KV 头、Query 头或 expert 数作为额外参数对照，检验收益是否仅来自扩容。
  2. 训练稳定性：Table 2 比较深度、学习率与 batch size；Dense 门控版本缩小 FFN，保持总参数一致。代价是同时改变 FFN 容量，不能把它当作其余架构完全不变的对照。
  3. 非线性：Table 3 用每头 RMSNorm、仅 SiLU、加法门控等探测中间特征变换的价值。归一化同时改变尺度，不能单独识别表达能力效应。
  4. 近零与输入依赖：Table 4 比较输入无关门控、共享门控及 NS-sigmoid；结合 Gate Score、首 token 权重与异常激活分析。
  5. 长度迁移：Table 5 在继续长上下文训练后再用 YaRN 外推，区分训练范围内表现与位置编码变换后的鲁棒性。

评估包括多领域 held-out PPL，以及 MMLU、GSM8K、HumanEval、HellaSwag、C-eval、CMMLU 等 few-shot 测试。PPL 越低越好，任务得分越高越好；不同表中的数据预算不同，不能跨表直接比较绝对 PPL。论文报告所测环境下门控 wall-time 增量小于 2%，这不是任意硬件、解码配置的性能保证。

“稀疏”应当怎样理解？

Figure 3 显示 G₁ 的分数大量集中在零附近；平均分数 0.116 本身不能充分描述分布。有限实数输入的 sigmoid 不产生严格零，这里主要是近似数值稀疏，不是 Top-K 跳算。门控在 SDPA 之后执行，不自动降低全注意力的二次计算复杂度。

NS-sigmoid(t) = 0.5 + 0.5σ(t) ∈ (0.5,1)

NS 版本保留非线性却不允许近零门控，PPL 从 5.761 变为 5.900，F-Attn 回到 0.451。这提供了支持“强抑制有价值”的干预证据，但激活均值、输出尺度和导数也一起改变，尚未完全隔离稀疏性。

输入无关的固定可学习门控弱于输入依赖门控。需要纠正一种容易出现的解释：虽然参数通过 sigmoid 生成，固定门控对激活 z 仍是线性缩放，可吸收到相邻投影，不能简单说它在输入函数中新增了非线性。其收益也可能来自重参数化和优化路径。

为什么 Gate 会改变在它之前计算的注意力图？

作者解释：当前 Query 依赖、头独立的近零门控能过滤无关上下文，减少依赖 Sink 承接冗余权重的需求。审稿推断：这是重新训练后的适应性变化；梯度同时改变 Q、K、V、WO 与 Gate。固定 Q/K 做一次前向传播时，G₁ 不会反过来修改刚刚算出的 a。不要把训练结果解释为 Gate 在推理中直接删除了首列权重。

Value Gate 将 M-Act 从 1053 降到 125，F-Attn 却仍为 0.297；共享 Gate 也有类似分离。这反驳了“压低异常激活就一定移除 Sink”的简单充分性叙述。作者认为巨大激活不是 Sink 的先决条件；更严格的判断还需说明异常激活阈值与逐层、逐头分布，这些汇总数值不能证明两种现象完全独立。

作者进一步推测，较小异常激活可能减少 BF16 数值误差并提升稳定性。这是合理机制线索，尚不能等同于对数值误差、梯度和 loss spike 之间完整因果链的证明。“Attention-Sink-Free”也应理解为所测配置中显著消退，而不是对任意输入、每个头零首位置权重的保证。

08 / Reviewer Assessment

结论证据判断尚缺什么
SDPA 输出门控改善性能较强：多位置、预算、Dense/MoE 对照更多尺度、训练体系与多随机种子复现
稳定训练范围扩大较强：深度、LR、batch 与 loss 曲线失败率统计和数值精度控制
非线性与近零控制发挥作用中等：消融方向一致尺度、梯度和参数预算严格匹配
门控训练显著减少 Sink较强：直接注意力测量分层分头、跨任务及不同长度分布
Sink 减少导致外推提升尚不充分：相关证据为主独立改变 Sink 的因果干预

主要贡献是可直接复用的架构选择和规模较大的系统消融。主要限制是机制因素耦合：位置同时改变信息条件性，NS-sigmoid 同时改变梯度与尺度，Dense 配平参数同时改变 FFN。表格未给出足以判断所有小差异显著性的重复试验区间，因此不能把每个小数点差异都解释成稳定规律。

注意力权重也不等价于实际功能贡献。要研究第 j 个 token 对当前输出的作用，应至少考虑 cᵢⱼʰ=(aᵢⱼʰvⱼʰ⊙gᵢʰ)WOʰ，再通过后续网络的干预验证；即使该向量范数很小，也不能直接推断最终任务影响为零。

09 / 后续研究：从相关性走向功能与因果

  1. 隔离稀疏性：比较均值与二阶矩匹配的连续门控、阈值门控和密集缩放；同步记录梯度、残差范数、PPL 与异常激活。若近零占比在尺度匹配后仍解释收益，才更接近独立机制证据。
  2. 验证 Query 依赖：把 gᵢ 换成同层其他 token 的 Gate、跨样本打乱或均值 Gate，并匹配输出尺度；比较损失上升与特定任务退化。区分信息选择与普通幅度正则化。
  3. 干预 Sink 与外推：在门控/无门控两种架构中，分别加入虚拟 Key、零 Value 或其他 Sink 干预；使用相同 RoPE/YaRN 与训练预算。检验独立压低 Sink 后，长上下文收益是否仍出现。
  4. 分离激活与精度：在受控小规模中比较 BF16/FP32，并记录逐层最大值、梯度峰值和 loss spike，测试稳定性收益是否主要由精度敏感性解释。
  5. 注意力头冗余：分别聚类 Attention Pattern、Gate Pattern、门控后 WO 投影输出；做单头与成组消融、Activation Patching，测 ΔNLL、任务得分与头间交互。相似 Sink 图不自动等于功能冗余；低平均 Gate 也不等于该头可安全永久剪除。
  6. 报告真实部署成本：测预填充、逐 token 解码、不同 batch 的延迟和显存；若要借近零门控跳算，应另设计提前预测与硬门机制。原论文的输出数值稀疏不能直接变成算力节省。

最有信息量的后续结果将是：在控制尺度和优化后，Gate 的输入依赖选择仍能解释独立收益；以及独立改变 Sink 能否复现或消除外推优势。两者分别检验表达机制与长上下文的因果机制。
