When Attention Sink Emerges in Language Models: An Empirical View

为什么自回归语言模型会把大量注意力权重分配给第一个 token？从训练动态、Key Bias 和 Softmax 归一化理解 Attention Sink。

快速总结

核心结论

某些 Attention Head 会将相当大的注意力权重分给序列初始 token。作者通过控制预训练条件发现 Sink 可以在训练过程中出现并迁移位置；添加可学习 Key 与零 Value 的虚拟位置能承接高权重；移除注意力的归一化约束可以显著抑制 Sink。

以下区分论文实测、前人工作与审稿推断。交互演示采用教学数值，不是论文测量结果。

01 / Research Problem

在 Decoder-only Transformer 中，一个 token 的 Query 只能关注当前及历史位置。即使第一个 token 没有明显语义价值，某些注意力头仍持续给予它很高权重，在注意力矩阵第一列形成亮带。这种现象称为 Attention Sink。

研究问题分为三个层次：Sink 在预训练哪个阶段出现？数据、训练目标、架构如何决定它的位置？模型为什么倾向于学到这种权重分配方式？回答这些问题，有助于解释流式 KV Cache、Attention Head 的功能和注意力架构设计。

02 / Prior Work

论文已有发现仍待解决
Quantizable Transformers (2023)特殊 token 的较小 Value 可帮助 Attention Head 近似执行 No-op；提出 Clipped Softmax、Gated Attention。为什么模型会自然学到首位置 Sink？
StreamingLLM (2023/24)保留起始 token 的 KV Cache 可提升流式解码稳定性。形成时机与驱动因素。
Massive Activations (2024)发现异常激活并关联 Sink 与隐式 Bias。归一化与预训练变量各发挥什么作用？

创新边界：本文没有首次发现 Attention Sink，也不是最早提出虚拟 Bias。核心增量在于系统的训练变量干预和对归一化机制的检验。

03 / Core Intuition

Softmax 强制把注意力权重分配完

aij = exp(sij) / Σm≤i exp(sim),　Σj≤i aij = 1

i 表示当前 Query 位置；j、m 表示因果遮蔽允许的 Key 位置；sij 是 Query-Key 缩放内积形成的 Logit；exp 是指数函数；Σ 表示求和；aij 是注意力权重。

当一个 Head 暂时没有值得从历史 token 读取的信息时，它仍须通过 Softmax 把全部权重分给某些位置。一种可行策略是将大部分权重分配给 Value 贡献接近零的 token，从而减少 Attention Output 对 Residual Stream 的更新。

进一步，Query 与 Key 的内积满足 q·k = ||q|| ||k|| cosθ。q、k 分别是 Query 和 Key 向量，||·|| 是欧氏长度，θ 是夹角。即便某个 Key 较短，只要方向与 Query 更接近，其内积仍可能很大。作者在 LLaMA3-8B Base 的观察支持这类 Q/K 几何解释。

为什么是首 token？首 token 在因果注意力下只看见自己，又始终对所有后续 token 可见，因此容易形成相对稳定的参考位置。但论文实验可以移动 Sink，表明它并非固定在位置 1 的硬编码结构。

04 / Method · Controlled Pre-training

Input：预训练配置

论文主要受控实验使用 LLaMA-style Decoder-only Transformer，10 层、8 Heads、Hidden Dimension 768、FFN Dimension 1536，约 60M 参数（不含 Embedding / Unembedding）；语料来自 The Pile，优化器为 AdamW。研究对象是预训练中逐渐形成的注意力模式。

Processing：Sink 指标

从每层每个 Head 提取注意力矩阵，计算位置 k 的平均被关注权重：

αk(l,h) = [1/(T−k+1)] Σi=k…T Ai,k(l,h)

l 为层编号，h 为 Head 编号，T 为序列长度，k 为候选 Sink 位置，i 遍历可关注 k 的 Query 位置；Ai,k 为该行对第 k 个 Key 的注意力权重。

再定义超过阈值 ε 的 Head 比例：

Sinkkε = [1/(L·H)] Σl=1…L Σh=1…H 1[αk(l,h) > ε]

L 是总层数，H 是每层的 Head 数；1[·] 为条件指示函数；ε 为阈值，论文默认 0.3。80 个 Head 中若有 24 个超过阈值，Sink 指标就是 30%，不代表 30% 的全模型注意力质量。

Intervention：可检验的操作

  1. 改变训练步数、学习率、数据供给，观察 Sink 何时形成。
  2. 改变固定或随机 token 的位置，以及 Prefix LM 训练目标，观察 Sink 是否迁移。
  3. 人工加入可学习的 Key Bias（Value 为零），测试虚拟位置能否承接 Sink。
  4. 比较 Softmax、归一化 Sigmoid 与非归一化 Sigmoid/ELU+1，检验归一化耦合。

Output 主要包括 Sink Head 占比和 Pile-CC Validation Loss，同时辅助分析 Q/K 方向与隐藏状态、Value 的范数。

05 / Key Results

实验 A：形成时间与位置

论文实测：在默认训练配置中，Sink 在约 1,000–2,000 步附近开始明显形成，学习率和数据量会影响出现过程；当训练数据中的初始位置被随机化或在后续位置插入固定 token 时，Sink 可发生迁移。

实验 B：K Bias 可以替代真实首 token 承接权重

新增虚拟 Key k* 和零 Value。对第 i 个 Query，Attention Output 可以表示为：

oi = ai,*·0 + Σj≤i aijvj

oi 是 Head 输出，ai,* 是虚拟 Key 的权重；vj 是原始 token 的 Value 向量。虽然虚拟位置不直接贡献 Value，其 Logit 仍参与 Softmax 分母并改变其他 token 的权重。

06 / Reviewer Assessment

优势：作者从静态热力图观察转向受控预训练干预。K Bias 加零 Value 的实验提供了较强功能证据，而归一化/非归一化 Sigmoid 对照有助于隔离 Attention Weight 耦合的作用。

限制：第一，Attention Weight 很高、Value Norm 较低不能直接推出最终 Logit 的因果贡献为零；需要 Head Output、K/V 替换和 Ablation 的进一步验证。第二，Sink 指标依赖序列长度、阈值和注意力定义。第三，小模型的验证损失不能直接代表长上下文任务、更大模型或者下游推理性能。

审稿判断

本文的重要价值是将 Attention Sink 转化为可干预检验的机制假说；它并未证明所有 Sink 都由同一机制产生，或 Sink 一定对下游表现有益。

07 / 后续研究：注意力模式冗余与功能冗余

可在 GPT-2 / Pythia 等自回归模型中研究三个层次：Pattern（Sink Score、JS Distance、Clustering）、Function（Value Contribution、Head Output、Ablation Loss）、Mechanism（训练动态、Key Bias 干预）。

待检验假设：两个 Head 即使都有相似的 Sink Pattern，也可能对模型输出承担不同功能。通过距离矩阵发现的 Attention Pattern Redundancy 不自动等价于 Functional Redundancy。
